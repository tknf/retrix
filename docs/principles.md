# デザインの原則

Retrixは、マスタ管理・顧客管理・案件管理・設定のような業務の画面を組み立てるためのデザインシステムです。手本は2012年前後の37signalsの画面（Basecamp 2・Highrise）です。表を中心にした一覧・詳細・編集の画面が最も得意ですが、それ以外の画面（文書、予定、連絡、ボード）も同じ作法で組めます。

見た目は雰囲気ではなく、手本の画面のスクリーンショットから測った値で決めます。測った値と、その根拠の画像は[見た目の根拠](visual-reference/README.md)にあります。この文書の数値は、そこからの抜き出しです。

## 当時の作りを守る

- **アニメーションとトランジションを使わない。** 開閉や状態の変化は、その場で切り替えます。
- **コンポーネントは平らな塗りにする。** Basecamp 2のコンポーネントは平らな色と1pxの枠と、ぼかしの無い1pxの影でできています。グラデーション・光沢・浮き彫りの文字は使いません。例外は、手本で確かめられたHighriseのページ送り（`Pagination`）の縦の塗りだけです。
- **使えない操作は文字だけを灰色にする。** 形・枠・塗りはそのままにし、斜線や半透明にしません。
- **片側だけの線と角丸を組み合わせない。** 線の端が角の丸みに沿って欠けるためです。片側に線を引く要素は角を立てます（`test/browser/edge-radius.spec.ts`で検出します）。
- **選択欄・チェックボックス・ラジオは、手本のMacの標準の部品を測って描く。** 手本はOSの標準の部品でしたが、今のブラウザの標準の部品は見た目が違うので、測った枠と縦の塗りで描きます（平らな塗りの例外）。

## 画面構成

- 地はクリーム色の机（`#f6f2e8`に細かいノイズ）で、その中央に白いシート（幅960px、内側の左右30px、角丸3px、枠なしの四方へのぼかしの影）を一枚置きます。画面の幅いっぱいには広げません。
- 内容が短い画面でも、作業面は画面の下端まで伸ばします。`Surface`は画面の高さを最小の高さとし、`AppShell`はヘッダー・フッターなどを除いた残りの高さを作業面に使います。内容が長い時は高さを自然に伸ばし、ページをスクロールして読みます。
- ヘッダーは帯を持たず、机の上に直接置きます。アプリの名前（20pxの太字の`#3d3c37`）、縦の区切り線（1px `#ded7c7`）、主な移動先（本文と同じ13pxの灰色、今いる項目は黒い太字）、検索欄（幅326pxまでの白い欄。枠なしで、シートと同じ影）を一行に並べ、アカウントへのリンクは上の行の右に小さく（11px）置きます。
- 上の階層は、シートの背後に重ねた淡い灰色のシート（`AppShell`の`trail`。`#f9f9f9`、1px `#e5e5e5`、影なし）で示します。背後のシートは手前のシートと同じ幅で、手前のシートの後ろを下端まで続きます。手前のシートは右へ21pxずれて重なるので、背後のシートは上の帯（見出しの18pxの太字のリンクを置く）と、左の細い帯が見えます。
- 分類ごとの移動先や最近見た項目は、シートの先頭側の列（`AppShell`の`aside`。Highriseの左の列）に置けます。列は机の上に置き、列とシートを合わせて中央に揃えます。
- シートの中で補足（担当者、関係者、操作のリンク）を並べる時は、本文の右側に細い列を作ります。

| 役割                   | 値                       | 使い方                                                   |
| ---------------------- | ------------------------ | -------------------------------------------------------- |
| 机                     | `#f6f2e8`                | 画面の地                                                 |
| シート・カード・パネル | `#ffffff`                |                                                          |
| 本文                   | `#000000`                | 本文・名前・題名は純黒                                   |
| 抜粋・説明             | `#666666`                |                                                          |
| 日付・補足             | `#7b6f54`                | 茶色（実測`#a89c80`を4.5:1まで濃くした値）               |
| リンク                 | `#1c5c77`と1pxの下線     | ホバーで赤                                               |
| まとまりの見出し       | `#990000`                | 15px・通常の太さ（カードや右の列の中は13pxの太字の黒）   |
| 主操作                 | `#008250`                | 平らな緑（実測`#00a264`を白い文字で4.5:1まで濃くした値） |
| 罫線                   | `#ececec`・`#dedede`     | 一覧の行の区切り・見出しの下                             |
| 黄色のハイライト       | `#ffffcc`                | 今日・選んだ行・新着                                     |
| 件数のピル             | `#e1e8f8`に`#1c5c77`     |                                                          |
| 担当者・期日のピル     | `#eeeeee`に`#6b6b6b`     |                                                          |
| 選んでいる項目         | `#ddeefe`に`#000000`     | メニューと候補の一覧で選んでいる項目の、角の無い淡い青   |
| 黄色の案内             | `#ffffcc`と1px `#eac73b` |                                                          |
| 使えない操作の文字     | `#9a9a9a`                | 形・枠・塗りはそのままにし、文字だけをこの灰色にする     |

- 白地の文字はWCAG 2.2のAA（4.5:1）を保ちます。実測の色が届かない時だけ、色合いを保って明るさを下げます（[実測から変えた値](visual-reference/README.md#実測から変えた値)）。
- 業務名や人物名から色を自動で割り当てません。

## 形

| 対象                                                  | 角丸                           |
| ----------------------------------------------------- | ------------------------------ |
| 控えめなボタン・複数行の入力欄・Pagination・Reactions | 5px（`--rx-radius-control`）   |
| ポップオーバー・メニューなどの浮かぶパネル            | 5px（`--rx-popover-radius`）   |
| 主ボタン                                              | 4px（`--rx-radius-primary`）   |
| シート・カード                                        | 3px（`--rx-radius-sheet`など） |
| 一行の入力欄・Badge・Tagなどの小さな要素              | 2px（`--rx-radius-mark`）      |
| 件数・担当者・期日のピル、カレンダーの終日の帯        | 高さの半分（ピルは9px）        |
| アバター                                              | 円                             |

- ピルの形は、上の表の件数・担当者・期日・カレンダーの終日の帯だけに使います。選んでいる状態をピルで囲みません。
- 状態（Badge）はHighriseの「WON」「CREATED」と同じく、濃い塗りに白い太字の角丸2pxの四角にします。色付きのTagも同じ塗りに白い文字です。

## 文字

文字の段は、ベースの本文（13px）から決めます。

| 役割                                           | トークン             | 大きさ                |
| ---------------------------------------------- | -------------------- | --------------------- |
| 補足・日時・ピル                               | `--rx-small`         | 11px                  |
| ボタン・入力欄・表・ラベル                     | `--rx-label`         | 12px                  |
| 本文・一覧の題名                               | `--rx-body`          | 13px                  |
| 続けて読む文章（コメント・カードの説明・文書） | `--rx-reading`       | 14px                  |
| まとまりの見出し                               | `--rx-section-title` | 15px、赤、通常の太さ  |
| シートの見出し                                 | `--rx-title`         | 18px、黒、太字        |
| 控えめなButton                                 | —                    | 高さ22px、largeは32px |
| 一行のInput                                    | —                    | 高さ24px、largeは32px |

- 一覧の題名はリンクの青緑の太字に下線、抜粋は灰色、日付は茶色にします（Basecamp 2の議論の一覧）。
- 手本（Basecamp 2）は英字で本文15px・ボタン12px・まとまりの見出し18〜19pxですが、和文は字面が大きく見えるので全体を一段下げ、段の比を手本に近づけています。
- 赤い見出しはシートの最上位のまとまりだけに使います。カード・分割した面・右の列・入れ子の`Section`の中の見出しは、本文の大きさ（13px）の太字の黒にします。
- 操作コンポーネントの文字は、枠の中で上下の中央に見えるよう専用のフォント定義（`--rx-control-font-family`）を使い、枠の内側の高さと文字の大きさの差を偶数にします。詳しくは[トークン](tokens.md#書体)を参照してください。

## リンクと操作

- リンクは青緑の文字に1pxの下線を引きます。ホバーすると赤になります。
- フォームの送信は主ボタン（緑）にし、取り消しはその右に「または　キャンセル」と文字のリンクで並べます。
- まとまりの見出しの右には、控えめなボタン（「新しい投稿」）を16px空けて置きます（手本の約17pxを4pxの段に丸めた値）。

## 状態

- **今いる場所**は黒い太字で示し、面や下線は付けません（ヘッダーの移動先）。縦に並べた移動先（Highriseの左の列）は、今いる行に淡い面を敷きます。
- **選んでいる項目**（DropdownMenu・FilterMenu・Picker・Suggestion・CommandMenuの候補など）は、角の無い淡い青（`--rx-option-active`）に黒い文字にします。FilterBarの条件やDialの値のように、選んだ値を示す所もピルで囲みません（Dialの選んだ値は黒い太字）。
- **選んだ行**は黄色のハイライトにします。
- **選んだ状態とオン**（チェックボックス・ラジオ・ToggleGroup・FilterBarの切り替え・選んでいるButton・選んだ日・Switch・書式ツール）は、手本のチェックボックスの選んだ状態と同じ、淡い青の縦の塗り（`--rx-selected-fill`）に紺の縁と紺の文字にそろえます。
- **使えない操作**は、形・枠・塗りをそのままにし、文字だけを灰色（`#9a9a9a`）にします。
- 色だけで状態を伝えません。

## まとまりの見出し

見出し、件数、操作の順に並べます。見出しから線は伸ばしません。線を引くのは、シートの見出しの下の罫線と、線そのものが役目のDividerだけです。

## 余白

- 段は4pxの倍数（4・8・12・16・20・24・32）を使います。手本で外れる値はシートの内側の30pxだけです。
- 器の中の段の間は、器の内側の余白よりはっきり狭くします。
- 余白は見える物（文字・入力欄・ボタン）から器の縁までで測ります。浮かぶパネル（Dialog・Popover）は上下左右を同じ余白にし、見出しと本文の間、本文の段の間、段の中の間の順に狭くします。
- 外側の余白は置く側（カード・パネル・シート）が持ちます。ValueListは上端と下端に余白を足さず、塗りのために行が上下の余白を持つ一覧（DataList・ActionList）は、器の端でその分を打ち消します。

## 配置

- Gridは列の対応があるところ（項目名と値、人物と本文、日付と内容）に使います。縮む列は`minmax(0, 1fr)`にします。
- Flexは内容の自然幅で並べるところ（操作群、分類名、件数）に使います。
- 入力・ボタンの内側はコンポーネント自身が持ち、親は外側の配置だけを持ちます。
- Container queryはコンポーネントの利用可能な幅で判断します。表と月のカレンダーは列の関係を保ったまま領域内でスクロールします。

## 役割の分担

- AppShellのヘッダーはアプリ全体の移動、CommandMenuは名前で探す移動と操作、DropdownMenuは対象に対する操作、Dialogは判断が必要な処理、Popoverは対象の近くの補足です。
- 継続して読む案内はNotice、修正先の一覧はErrorSummary、何もない理由はEmptyState、測れる進み具合はProgress、待機はLoading、結果の通知はToastにします。
- 業務データ・権限・通信・永続化は利用するアプリが持ちます。Retrixは情報の読み順・配置・操作を共通化します。
