## Retrix への提案

- **色のトークン**
  - `--rx-desk: #f6f2e8`（BC2）＋ノイズの画像（明るさだけ、標準偏差 3/255 ≒ 1.2%、粒 1px 前後、縦に少し長い）。Highrise 風の版は `#f4f1ec` の平らな面。
  - `--rx-sheet: #ffffff`、`--rx-sheet-parent: #f9f9f9`（枠 `--rx-border-parent: #e5e5e5`）、`--rx-band: #f5f5f5`（Me の帯。下に `#ebebeb`）、Highrise の帯 `--rx-band-blue: #f6f9fe`（下に `#dfdee3`）。
  - 罫線: `--rx-rule: #dedede`（見出しの下）、`--rx-rule-row: #ececec`（一覧の行）、`--rx-rule-footer: #e5e5e5`、`--rx-rule-grid: #e9e9e9`、ヘッダーの区切り `#ded7c7`。
  - 文字: `--rx-text: #000`、`--rx-text-muted: #666`、`--rx-text-ui: #7a7a72`、`--rx-text-faint: #a9a8a4`、`--rx-text-khaki: #a89c80`、`--rx-link: #1c5c77`、`--rx-heading: #990000`（Me 系は `#a52a2a`）、ロゴの文字 `#3d3c37`。
  - Highrise: 帯のグラデーション `#3a719a → #255981`、下の縁 `#2a5879`、左の列の文字 `#51504c`・件数 `#959490`・アイコン `#c5c5c5`・今いる行 `#e6e3de`、彫り込みの線 `#dbdad6` / `#fffefc`。
- **影**: `--rx-shadow-sheet: 0 0 6px rgba(0,0,0,.28)`（四方に均等、ずらしなし。検索欄も同じ）、`--rx-shadow-card: 0 0 4px rgba(0,0,0,.2)`（推定。カードはシートより短い）。親のシートは影なしで 1px の枠。Highrise のシートは `1px solid #d9d9d9` ＋ `0 1px 3px rgba(0,0,0,.08)`（推定）。
- **角丸**: シート・カード・検索欄とも `3px`。
- **寸法**: シート幅 `960px`、シートの内側の余白 `30px`（4の倍数に寄せるなら `32px`）、ヘッダーの領域 `92px`、カード `240×264`・間 `20px`、親のシートのずれ `translate(20px, 60px)`。
- **文字**: `font-family: "proxima-nova", "Helvetica Neue", Helvetica, Arial, sans-serif`。大きさの段は 11・13・15・16・18・20・24（一覧の本文 15/18、コメントの本文 16/20、セクションの見出し 18 で太さ 400 の赤、プロジェクト名 24 太字の黒）。リンクは下線 1px、`text-underline-offset: 1.5px` 前後。今いる移動先は色を黒にし、太字にするだけで面は付けない。
