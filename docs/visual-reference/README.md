# 見た目の根拠（実測）

Retrixの見た目は、雰囲気ではなく、Basecamp 2（2012〜2015）とHighrise（2011〜2013）の画面のスクリーンショットから測った値で決めます。このフォルダは、その測定の記録です。

| ファイル                     | 内容                                                                   |
| ---------------------------- | ---------------------------------------------------------------------- |
| [controls.md](controls.md)   | ボタン・入力欄・選択欄・チェックボックス・ラジオ・フォーカス・無効     |
| [structure.md](structure.md) | 机・シート・背後のシート・ヘッダー・見出し・文字・余白・Highriseの構成 |
| [overlays.md](overlays.md)   | ポップオーバー・メニュー・確認・タブ・案内・ページ送り・パンくず       |
| [lists.md](lists.md)         | 一覧・To-do・ファイル・表・タグ・件数・カレンダー                      |

- 画像のパスは、リポジトリの`screenshots/`（容量が大きいためコミットしない）からの相対パスです。各記録の「切り出し」は測定の作業用の画像で、リポジトリには含めていません。
- 座標は元の画像の画素です。Retinaの2倍の画像は、画素を2で割ってCSSのpxにしています。倍率の判断の理由は各記録の冒頭にあります。
- 測れなかった項目は「不明」、推測は「推測」と書いています。推測で決めた値は、手本が見つかったら置き換えます。

## 実測から変えた値

Retrixは文字のコントラストをWCAG 2.2のAA（4.5:1）で保ちます。実測の色が白地で4.5:1に届かない時だけ、色合いを保ったまま明るさを下げています。

| 対象                           | 実測                       | Retrix    | 白地のコントラスト（実測 → Retrix） |
| ------------------------------ | -------------------------- | --------- | ----------------------------------- |
| 日付・補足の茶色               | `#a89c80`                  | `#7b6f54` | 2.7 → 5.0                           |
| ヘッダーの移動先・小さなリンク | `#7a7a72`（机の上）        | `#6e6e67` | 3.9 → 4.6（机の上）                 |
| 主ボタンの緑                   | `#00a264`                  | `#008250` | 3.3 → 4.9（白い文字）               |
| 担当者・期日のピルの文字       | `#777777`（`#eeeeee`の上） | `#6b6b6b` | 3.9 → 4.6（ピルの地の上）           |

使えない操作の文字（`#9a9a9a`）は、WCAG 2.2の1.4.3が使えない操作の対比を求めないため、実測のまま使います。
