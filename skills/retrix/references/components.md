# コンポーネント

全コンポーネントのリファレンスです。カタログの各ページ（`/components/<id>`）と同じ内容で、見本の表示はカタログで確認できます。

## 作業面と移動

- [AppShell](https://github.com/tknf/retrix/blob/main/docs/components/app-shell.md)：机の上に白いシートを置く、アプリの基本の画面構成です。ヘッダーと作業面を画面の中央に揃えます。
- [CommandMenu](https://github.com/tknf/retrix/blob/main/docs/components/command-menu.md)：ヘッダーの末尾側に置く検索欄から開き、アプリ全体の移動先と操作を名前で探します。
- [SplitView](https://github.com/tknf/retrix/blob/main/docs/components/split-view.md)：一覧と本文、作業と補足を並べて表示します。
- [Wing](https://github.com/tknf/retrix/blob/main/docs/components/wing.md)：中央の作業面の左右に、開閉できる補助パネルを置きます。
- [Section](https://github.com/tknf/retrix/blob/main/docs/components/section.md)：関連する内容を、見出し・件数・操作と一緒にまとめます。
- [Surface](https://github.com/tknf/retrix/blob/main/docs/components/surface.md)：机の上に置く白いシート（作業面）です。AppShellの作業面と同じ見た目で、AppShellを使わない画面で使います。
- [ContextBar](https://github.com/tknf/retrix/blob/main/docs/components/context-bar.md)：現在の位置と、関連する移動・操作を作業面の上部にまとめます。
- [PageHeader](https://github.com/tknf/retrix/blob/main/docs/components/page-header.md)：対象と作業を、大きな見出しで伝えます。
- [ProfileHeader](https://github.com/tknf/retrix/blob/main/docs/components/profile-header.md)：人物の写真と名前に、その人に関する設定を並べます。
- [Breadcrumb](https://github.com/tknf/retrix/blob/main/docs/components/breadcrumb.md)：階層をたどって、上の階層へ戻ります。
- [BackLink](https://github.com/tknf/retrix/blob/main/docs/components/back-link.md)：一つ上の階層へ戻るためのリンクです。
- [Navigation](https://github.com/tknf/retrix/blob/main/docs/components/navigation.md)：同じ領域のページを切り替えます。
- [Tree](https://github.com/tknf/retrix/blob/main/docs/components/tree.md)：作業面の中で、階層を開閉して項目を選択します。
- [TableOfContents](https://github.com/tknf/retrix/blob/main/docs/components/table-of-contents.md)：長い資料の見出しへ移動し、現在の位置を示します。
- [Tabs](https://github.com/tknf/retrix/blob/main/docs/components/tabs.md)：同じ場所で、関連するパネルを切り替えます。
- [Pagination](https://github.com/tknf/retrix/blob/main/docs/components/pagination.md)：分割された一覧のページを移動します。
- [Steps](https://github.com/tknf/retrix/blob/main/docs/components/steps.md)：手順と現在の段階を示します。
- [Divider](https://github.com/tknf/retrix/blob/main/docs/components/divider.md)：内容の区切りに線を引き、見出しや操作を置きます。

## 入力と選択

- [Field](https://github.com/tknf/retrix/blob/main/docs/components/field.md)：ラベル・入力欄・補足・エラーを関連付けます。
- [FieldGroup](https://github.com/tknf/retrix/blob/main/docs/components/field-group.md)：見出し・説明・入力欄を、ひとまとまりのフォームとして配置します。
- [OptionalFields](https://github.com/tknf/retrix/blob/main/docs/components/optional-fields.md)：必要な時だけ追加する入力欄と、追加できる項目のチップです。
- [InputGroup](https://github.com/tknf/retrix/blob/main/docs/components/input-group.md)：入力欄の前後に、単位や接頭辞を並べます。
- [CopyField](https://github.com/tknf/retrix/blob/main/docs/components/copy-field.md)：コピーして使う値を表示する欄と、コピーボタンです。
- [Switch](https://github.com/tknf/retrix/blob/main/docs/components/switch.md)：オン・オフの設定を切り替えます。
- [ToggleGroup](https://github.com/tknf/retrix/blob/main/docs/components/toggle-group.md)：関連する状態を、一つまたは複数切り替えます。
- [Range](https://github.com/tknf/retrix/blob/main/docs/components/range.md)：スライダーで、数値や範囲を調整します。
- [Dial](https://github.com/tknf/retrix/blob/main/docs/components/dial.md)：つまみの周りに並べた選択肢から、一つを選びます。
- [Suggestion](https://github.com/tknf/retrix/blob/main/docs/components/suggestion.md)：自由に入力できる欄に、候補を表示します。
- [Picker](https://github.com/tknf/retrix/blob/main/docs/components/picker.md)：検索して、候補から値を選びます。
- [EmojiPicker](https://github.com/tknf/retrix/blob/main/docs/components/emoji-picker.md)：絵文字を検索して選ぶパネルです。
- [InlineSelect](https://github.com/tknf/retrix/blob/main/docs/components/inline-select.md)：文中の語をクリックして、選択肢から選びます。
- [ColorPicker](https://github.com/tknf/retrix/blob/main/docs/components/color-picker.md)：色相・彩度・明度・不透明度を、見本を確認しながら選びます。
- [TagInput](https://github.com/tknf/retrix/blob/main/docs/components/tag-input.md)：入力した文字をタグとして追加・解除します。
- [DatePicker](https://github.com/tknf/retrix/blob/main/docs/components/date-picker.md)：日付や期間を、一つの入力欄で選びます。
- [DateTimeRange](https://github.com/tknf/retrix/blob/main/docs/components/date-time-range.md)：開始と終了の日時を並べて入力します。
- [FileInput](https://github.com/tknf/retrix/blob/main/docs/components/file-input.md)：ファイルを選択し、添付する内容を確認します。
- [ImageCropper](https://github.com/tknf/retrix/blob/main/docs/components/image-cropper.md)：画像の切り抜く範囲を、画像の上の操作と数値の両方で調整します。
- [Composer](https://github.com/tknf/retrix/blob/main/docs/components/composer.md)：本文・添付・送信の操作を、一つの入力エリアにまとめます。
- [TextEditor](https://github.com/tknf/retrix/blob/main/docs/components/text-editor.md)：書式ツールを並べた入力エリアです。
- [FilterBar](https://github.com/tknf/retrix/blob/main/docs/components/filter-bar.md)：一覧の絞り込み条件を、リンクで切り替えます。

## 操作と補足

- [Button](https://github.com/tknf/retrix/blob/main/docs/components/button.md)：操作の主従、無効、処理中を表します。
- [SplitButton](https://github.com/tknf/retrix/blob/main/docs/components/split-button.md)：主な操作のボタンと、別の方法を選ぶ▾のボタンをつなげて並べます。
- [ActionTile](https://github.com/tknf/retrix/blob/main/docs/components/action-tile.md)：塗りつぶしのアイコンと名前を縦に並べたタイルです。リンクや操作をグリッドに並べます。
- [Toolbar](https://github.com/tknf/retrix/blob/main/docs/components/toolbar.md)：対象に対する複数の操作をまとめます。
- [ActionDock](https://github.com/tknf/retrix/blob/main/docs/components/action-dock.md)：画面の下に表示する操作バーです。アイコン・名前・ショートカットキーを並べます。
- [DropdownMenu](https://github.com/tknf/retrix/blob/main/docs/components/dropdown-menu.md)：現在の対象に関する補助の操作をまとめます。
- [FilterMenu](https://github.com/tknf/retrix/blob/main/docs/components/filter-menu.md)：文字を入力して候補を絞り込み、選択する小さなパネルです。
- [Dialog](https://github.com/tknf/retrix/blob/main/docs/components/dialog.md)：今の画面を離れずに、操作の影響や内容を確認します。
- [Popover](https://github.com/tknf/retrix/blob/main/docs/components/popover.md)：補足の説明や小さな操作を、必要な時に開いて表示します。
- [Tooltip](https://github.com/tknf/retrix/blob/main/docs/components/tooltip.md)：操作に添える短い補足を、ホバーとフォーカスで表示します。
- [HoverCard](https://github.com/tknf/retrix/blob/main/docs/components/hover-card.md)：対象の概要と関連する操作を、近くに表示します。
- [Disclosure](https://github.com/tknf/retrix/blob/main/docs/components/disclosure.md)：補足の内容を、HTMLの標準の要素で開閉します。
- [DangerZone](https://github.com/tknf/retrix/blob/main/docs/components/danger-zone.md)：削除や公開の取り消しなど、影響の大きい操作を説明と一緒にまとめます。
- [Keycap](https://github.com/tknf/retrix/blob/main/docs/components/keycap.md)：キーボードのキーの表記をそろえて表示します。

- [Avatar](https://github.com/tknf/retrix/blob/main/docs/components/avatar.md)：人物やチームを、名前と一緒に示します。

- [CodeBlock](https://github.com/tknf/retrix/blob/main/docs/components/code-block.md)：設定や短いコードを、改行を保って表示します。

## 状態と結果

- [Badge](https://github.com/tknf/retrix/blob/main/docs/components/badge.md)：短い状態を、文言と役割の色で示します。
- [Notice](https://github.com/tknf/retrix/blob/main/docs/components/notice.md)：事実・影響・次の操作を、画面に残る形で示します。
- [Prompt](https://github.com/tknf/retrix/blob/main/docs/components/prompt.md)：質問をパネルの上に置き、回答の選択肢を全幅のボタンで並べます。
- [ErrorSummary](https://github.com/tknf/retrix/blob/main/docs/components/error-summary.md)：送信時のエラーと、修正する欄へのリンクをまとめます。
- [EmptyState](https://github.com/tknf/retrix/blob/main/docs/components/empty-state.md)：表示する情報がない理由と、次の操作を示します。
- [Progress](https://github.com/tknf/retrix/blob/main/docs/components/progress.md)：処理の進み具合を示します。終わりが分からない処理にも使えます。
- [Loading](https://github.com/tknf/retrix/blob/main/docs/components/loading.md)：読み込み中の処理を、文言とインジケーターで示します。
- [Toast](https://github.com/tknf/retrix/blob/main/docs/components/toast.md)：操作の結果を、閉じるまで読める通知として表示します。
